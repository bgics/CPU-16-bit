	\begin{itemize}[itemsep = -0.75 mm, leftmargin=*]
		\item Designed and implemented a 16-bit RISC microprocessor in VHDL with a 20-state FSM controller executing 16 instructions including arithmetic (ADD, SUB, MUL), logical (AND, OR, IMP), memory (LW, SW), and branching operations (BEQ, JAL, JLR)
		\item Implemented datapath with 8 general-purpose registers, 16-bit ALU, dual-port register file, and separate instruction/data memory for multicycle instruction execution
		\item Designed FSM state transitions with state merging to reduce complexity by 25\% and minimize clock cycles per instruction
		\item Implemented and tested a Fibonacci number generator on FPGA hardware to verify correct operation across arithmetic, memory access, and control flow instructions
		\item Developed a Python-based assembler that parses assembly code and generates binary machine code, directly writing to \texttt{im\_memory.vhd}
	\end{itemize}
