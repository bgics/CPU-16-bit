		\item Implemented state merging and transition optimization to reduce FSM complexity by 25\% and minimize clock cycles per instruction
		\item Developed a Python-based assembler that parses assembly programs and automatically generates binary machine code for \texttt{im\_memory.vhd}
		\item Implemented and tested a Fibonacci sequence generator on FPGA hardware to verify correct processor operation and instruction execution
