	\begin{itemize}[itemsep = -0.75 mm, leftmargin=*]
		\item Designed and implemented a 16-bit RISC microprocessor in VHDL with a 20-state Finite State Machine (FSM) controller that executes 16 instructions including arithmetic operations (ADD, SUB, MUL), logical operations (AND, OR, IMP), memory access (LW, SW), and control flow (BEQ, JAL, JLR)
		\item Implemented datapath with 8 general-purpose registers, 16-bit ALU, dual-port register file, and separate instruction and data memory for multicycle instruction execution
		\item Designed hardware state transition diagrams with state merging to reduce FSM complexity by 25\% and minimize clock cycles per instruction
		\item Implemented and tested a Fibonacci sequence generator on FPGA hardware to verify processor functionality across arithmetic operations, memory access, and control flow instructions
		\item Developed a Python-based assembler that parses assembly code and generates binary machine code, directly writing to \texttt{im\_memory.vhd} to automate the compilation process
	\end{itemize}
