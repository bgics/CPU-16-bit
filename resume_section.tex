	\begin{itemize}[itemsep = -0.75 mm, leftmargin=*]
		\item Architected and implemented a 16-bit RISC microprocessor in VHDL, featuring a 20-state Finite State Machine (FSM) controller that executes 16 distinct instructions including arithmetic operations (ADD, SUB, MUL), logical operations (AND, OR, IMP), memory access (LW, SW), and control flow (BEQ, JAL, JLR)
		\item Designed an optimized datapath with 8 general-purpose registers, a 16-bit ALU supporting 8 operations, dual-port register file, and hierarchical memory system (instruction and data memory) to achieve efficient pipelined execution
		\item Engineered optimal hardware state transition diagrams minimizing clock cycles per instruction, reducing FSM complexity by 25\% through strategic state merging and parallel operation scheduling, resulting in improved throughput
		\item Developed and successfully deployed a Fibonacci sequence generator on FPGA hardware, validating processor functionality through comprehensive testing of arithmetic operations, memory management, and loop control mechanisms
		\item Built a Python-based assembler with custom instruction parsing and binary code generation, automating the compilation of assembly programs to machine code and directly writing to \texttt{im\_memory.vhd}, reducing development cycle time by eliminating manual binary encoding
	\end{itemize}
